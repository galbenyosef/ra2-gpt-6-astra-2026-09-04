# Menu typeface

Fira Sans Condensed Latin weights 500 and 700 are the exact WOFF2 files used by
both local Chrono Divide references. They originated from Google Fonts; each font
retains its original name and bytes. `fonts.css` declares the faces and CJK fallback.
See `OFL.txt` for the SIL Open Font License and copyright notice, sourced from
https://github.com/google/fonts/tree/main/ofl/firasanscondensed.
These are open font assets, separate from locally extracted original game media.
